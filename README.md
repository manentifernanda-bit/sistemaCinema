## Sobre o sistema

Este projeto consiste no desenvolvimento de um Sistema de Gerenciamento de Cinema, desenvolvido com o objetivo de aplicar, na prática, os principais conceitos da Programação Orientada a Objetos (POO).
O sistema permitirá o gerenciamento de informações relacionadas a filmes, clientes, funcionários, salas, sessões e ingressos.

## Objetivo

O objetivo do sistema é facilitar o gerenciamento das atividades de um cinema, permitindo realizar operações de cadastro, consulta, atualização e remoção de informações.

## Conceitos de Programação Orientada a Objetos

Durante o desenvolvimento do projeto serão utilizados os seguintes conceitos:

Classes e Objetos
Encapsulamento
Herança
Polimorfismo
CRUD
ArrayList

Os conceitos de herança e polimorfismo serão utilizados para representar diferentes tipos de pessoas e filmes dentro do sistema. Os atributos das classes serão encapsulados por meio de modificadores de acesso e métodos getters e setters.

## Principais Classes

Pessoa:
Classe base para representar as pessoas relacionadas ao sistema.

Cliente:
Representa os clientes do cinema.

Funcionário:
Representa os funcionários responsáveis pelas atividades do cinema.

Filme:
Representa os filmes disponíveis no cinema.

Filme3D:
Classe derivada de Filme, representando filmes exibidos em tecnologia 3D.

FilmeNormal:
Classe derivada de Filme, representando filmes exibidos no formato convencional.

Sala:
Representa as salas de exibição do cinema.

Sessão:
Representa as sessões dos filmes, contendo informações como data, horário e sala.

Ingresso:
Representa os ingressos adquiridos pelos clientes para determinada sessão.

## Funcinalidades:
O sistema contará com funcionalidades para:
Cadastrar filmes;
Listar filmes;
Buscar filmes;
Atualizar informações de filmes;
Remover filmes;
Cadastrar clientes;
Listar clientes;
Buscar clientes;
Atualizar clientes;
Remover clientes;
Cadastrar salas;
Cadastrar sessões;
Realizar o gerenciamento de ingressos.
